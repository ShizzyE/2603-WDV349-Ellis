## Web Designs, colors, patterns, and branding
A lot of modern web designs follow a minimalistic--simplistic design flow.

## UI Libraries for NextJS
The majority of UI libraries that are for React are also compatible with NextJS but may need some configurations. The main UI libraries that are popular with NextJS are Shadcn/ui, Material UI (MUI), and Chakra UI. 

Key Findings 🔎 :
1. A lot of the top UI libraries allow you to customize your designs the way you would like instead of handicapping you to a certain design style. This is important when you want to have full autonomy over how you want your website flow to look and feel. 
2. Different UI libraries have specialties like data analysis or B2B focused designs.
3. Utilizing a UI library can rapidly increase development processes and allows for more design control.
