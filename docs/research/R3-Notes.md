## UI/UX Rules and Tips
When designing a webpage, consistency and cohesion are essential. Users should be able to navigate, interact with, and understand the interface quickly and efficiently.

Key Findings 🔎 :
1. Having a plan before you develop is a massive advantage. It allows you plan out user flow and how you want the webpage to flow and look.
2. Never overload the user with too many options and visual distractions. Make the user interface as clear and intentional as possible without making it hard to navigate
3. Using familiar UI patterns (such as navigation menus, buttons, and forms) helps users interact with the interface more intuitively. Designers can build on these patterns while adding their own visual style.

## Using Python effectively with FastAPI
FastAPI is one of the three most popular web frameworks for Python. It offers high-performance with it being built on top of the Starlette framework web handling.

Key Findings 🔎 :
1. FastAPI can automatically validate and convert incoming JSON to Python objects before endpoint logic runs. 
2. You can locally test your code with Uvicorn to help with workflow.
3. You can code way faster with FastAPI compared to the other Python web frameworks.

<br>

## SQLAlchemy + FastAPI
FastAPI and SQLAlchemy, combined together, are perfect for Python APIs that use and interact with a relational database.

Key Findings 🔎 :
1. SQLAlchemy as an ORM allows you to interact with the database with Python objects instead if writing raw SQL queries.
2. The database tables are presented as Python classes/ models, making it easier to structure and manage app data.
3. SQLAlchemy uses sessions to handle database transactions.FastAPI can manage these sessions using dependency injections to ensure clean and efficient database operations.
