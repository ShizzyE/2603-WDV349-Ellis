## Web Application Security
The OWASP recommendations for preventing and mitigating prompt injection are especially relevant to PlanBuddy because the application uses an AI-assisted task agent. One important strategy is to clearly define the AI's role and limitations so that it stays focused on helping users with tasks instead of following potentially harmful instructions. I also learned that inputs and outputs should be filtered and validated to prevent the AI from processing or producing inappropriate or malicious content. Another important strategy is using the principle of least privilege, which means the AI should only have access to the information and functions it actually needs to perform its job. For higher-risk actions, having human approval before the AI can make changes would provide an additional layer of security. External or untrusted content should also be separated from trusted instructions so that the AI is less likely to treat malicious content as a legitimate command. Overall, these strategies showed me that because AI systems cannot be completely protected from prompt injection, PlanBuddy should focus on limiting the potential impact of an attack through careful design, access controls, validation, and ongoing security testing.

## Code Scanning
CodeQL is a code scanning tool from GitHub that can identify potential vulnerabilities and errors within a project. One thing I learned is that CodeQL does not require a repository to be public, although the available code-scanning features can depend on the GitHub plan being used. CodeQL can be configured through GitHub's default setup, an advanced setup, or by running the CodeQL CLI through an external CI system and uploading the results to GitHub. The default setup seems useful for getting started quickly because GitHub can automatically configure the scanning process for supported projects. The advanced setup provides more control over how and when the code is analyzed, which could be useful as PlanBuddy becomes more complex. Using a tool like CodeQL could help me identify security vulnerabilities earlier in development instead of discovering them after deployment. In knowing this, I think incorporating automated code scanning into PlanBuddy's development process could improve the project's overall security and help me catch potential problems before they become larger issues.
