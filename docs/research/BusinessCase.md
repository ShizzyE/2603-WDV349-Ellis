# Business Case Research

Many productivity apps require users to do most of the planning and organizing themselves, which can become overwhelming and time-consuming. PlanBuddy aims to solve this problem by helping users plan their schedules, organize their tasks, and save valuable time. In today’s fast-paced society, having time for yourself is just as important as getting things done. We are not robots, so why not let one assist with the planning—or even handle some of the work for you? PlanBuddy is designed to reduce the stress of planning so users can spend less time organizing and more time accomplishing their goals. By reducing the amount of manual planning users have to do, PlanBuddy can provide value by saving time, reducing decision fatigue, and making productivity tools easier to use.


## A/B Testing

For PlanBuddy's first release, we are exploring two ways to implement AI assistance. The first approach would have AI built directly into task creation and planning, allowing the AI to assist users automatically. The second approach would provide users with a dedicated AI chat where they can create their own prompts and decide how they want the AI to assist them. This second approach could also include a small PlanBuddy AI feature integrated throughout the application that provides notes, ideas, or suggestions based on the page the user is currently viewing. A/B testing these approaches could help determine which option provides the better user experience and makes planning easier for users.


## Use Cases

The use case for PlanBuddy will focus on a user logging in, creating a new task, and providing information about what they need to accomplish. The user can then choose to have AI assist with planning the task, creating additional tasks, or providing suggestions. After reviewing the AI's response, the user can accept or modify the suggestions before saving the task. The test will verify that the task is successfully created and displayed in the user's task list. We will also test alternate and exception scenarios, such as the AI creating tasks based on previous conversations, AI assistance being unavailable, incomplete information being provided, or a task failing to save. These tests will help ensure that PlanBuddy responds correctly to both normal and unexpected user actions.
