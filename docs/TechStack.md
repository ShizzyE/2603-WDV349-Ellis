# Tech Stack 🛠️


## Application Design 🎨

Figma will be the primary tool used for creating all designs and prototypes. I already have significant experience with Figma, which will help streamline my workflow and allow me to work more efficiently. For the UI components in this project, I plan to use **shadcn/ui** because it provides a modern development experience and integrates well with the frameworks I will use like React and Next.js. Using this library will also allow me to expand my knowledge and gain experience working with different component libraries.


## React + Next.js 🖥️ (Frontend)

For the frontend i will use React with Next.js to build a modern looking, server-side rendered and client-side interactive app. The approach I will use includes component-based architecture, routing & data fetching, state management (using redux), and API integration throughout the app. 


## Redux 🔄 (State-Management)

For client-side data management, I will use Redux, while all persistent data will be stored in PostgreSQL. Items such as AI responses, user login tokens, and user prompts will be stored in the PostgreSQL database for history and persistence. Temporary data, such as AI suggestions, will be managed in Redux.


## Python 🐍 (Backend)

I will use Python as the backend language to handle all server-side logic, API endpoints, and data processing. Python’s readability and ecosystem make it ideal for building a scalable API, integrating with databases like PostgreSQL, and connecting to AI services such as the OpenAI API.


## FastAPI ⚡️ (Backend)

FastAPI is a modern Python framework for building APIs quickly and efficiently. It allows you to define routes, controllers, and endpoints that handle incoming requests and return JSON responses.


## PostgreSQL 🐘 + SQLAlchemy 🧪 (Database)

Having some familiarity with Sequelize I look forward to using SQLAlchemy as an ORM for PostgreSQL inside of this project. In theory it should be easy to learn because it's understanding the syntax, but I'm excited for any challenge that comes along.


## OpenAI API + LangGraph 🤖 (AI + Agent)

To integrate AI into my project and handle prompts efficiently, I will use the OpenAI API along with LangGraph as my AI agent. For testing, I plan to use OpenAI’s GPT‑3.5 Turbo API.
