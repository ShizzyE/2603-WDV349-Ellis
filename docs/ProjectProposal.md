# PlanBuddy 

## Application Definition Statement

PlanBuddy is a personalized AI powered task manager app that helps users plan, prioritize, and track their tasks efficiently, while optimizing time management.


## Target Market

PlanBuddy aims to provide busy professionals and anyone looking to improve their time management with an easy and effective way to organize their tasks. While there is no age requirement for being productive, the primary users are likely adults between ages 20-45, including college students, early career employees, and any type of professional. These users usually have post-secondary eduction and are employed at places such as tech, business, or healthcare industries where managing multiple tasks and deadlines is essential.

Many of these users have a moderate to high income level and are motivated to optimize their workflow, reduce stress, and use their time better. They are likely to have hobbies that involve planning, goal setting, or overall self improvement, and they may already use digital tools for scheduling, reminders, or productivity tracking.

## Use Cases

Use Case 1: Adding and Completing a Task
Goal: The user wants to quickly add a new task and mark it as complete when finished.

Steps:

1. User opens PlanBuddy and navigates to the To-Do List.
2. User clicks “Add Task” and enters the task name, due date, and optional priority.
3. User clicks “Save” amd the task appears in the task list and on the calendar.
4. When the task is completed, the user clicks the checkbox next to the task.
5. The AI provides optional feedback or suggests the next task based on priority and deadlines.

Problem Solved:
 - Reduces forgetfulness and keeps all tasks organized in one place.
 - Helps the user maintain a clear workflow with minimal clicks.


Use Case 2: Using the AI Prompter to Ask Questions
Goal: The user wants to ask questions about task management, productivity tips, or app functionality without leaving PlanBuddy.

Steps:
1. User opens PlanBuddy and navigates to the AI Prompter tab.
2. User types a question or request, such as:
  - “Which task should I focus on first today?”
  - “How can I break this task into smaller steps?”
  - “What’s the best way to manage my schedule this week?”
3. The AI analyzes the user’s tasks, priorities, and context.
4. The AI responds with actionable advice, suggestions, or step-by-step guidance.
5. User can follow the AI’s suggestions to:
  - Add subtasks
  - Adjust priorities
  - Schedule tasks in the calendar
6. User can ask follow up questions or request clarification at any time.

Problem Solved:
 - Reduces confusion and decision fatigue when planning tasks.
 - Provides on-demand guidance and productivity tips.
 - Keeps the user focused without needing to search external resources or switch apps.


## Problem Statement

Although there are task managing apps out there, many are too complex. With the addition of AI, PlanBuddy will a user friendly interface and AI assisted task management suggestions for users who want simplicity and efficiency. PlanBuddy will also help people who are completely new to organizing their tasks.


## Pain Points

Pain points for most people with task management :

1. Difficulty Prioritizing Tasks and not knowing what to tackle first leads to wasted time.
2. Using Multiple Tools to manage tasks. Switching between calendars, notes, and reminders can be confusing.
3. Feeling Overwhelmed with too many tasks without a clear plan creates stress.
4. Time Wasted on planning and organizing tasks than actually completing them.


## Solution Statement

With these pain points in mind, PlanBuddy will offer an all in one calendar, note, and to-do-list task management system. The AI assistant can help with priority suggestions and even can be prompted for ideas on how to plan out your week. Tasks can be easily written down and separated by days instead of being thrown at your face all at once. 


## Competition

There are many task manager apps available, but three notable examples are Asana, Google Tasks, and Notion.

- Asana focuses on project and team task management, which can be overwhelming for individual users who only need to manage personal tasks.

- Notion offers a highly customizable workspace for both task and time management, but its complexity can be a barrier for users looking for simplicity.

- Google Tasks provides a straightforward way to track daily tasks, but it lacks customization and visual appeal.

PlanBuddy differentiates itself by combining simplicity, customization, and a visually engaging interface. It allows users to easily organize and prioritize tasks while enjoying a modern, colorful, and AI supported experience that helps them stay productive without feeling overwhelmed.


## Features & Functionality

1. AI Suggestions
 In order to prioritize tasks and reduce decision fatigue, I need AI-powered suggestions for what tasks to focus on first.

   - The AI will analyze the user’s tasks, deadlines, and habits to recommend the most important or time sensitive tasks.

   - This addresses the pain points of feeling overwhelmed and having difficulty prioritizing daily work.

2. Built-in Calendar
 In order to stay organized and visualize deadlines, I need an integrated calendar to see tasks and events in one place.

   - Users can view tasks by day, week, or month, and schedule new tasks directly on the calendar.

   - This solves the problem of juggling multiple tools and helps users keep track of deadlines efficiently.

3. CRUD To-Do List
 In order to manage tasks effectively, I need the ability to Create, Read, Update, and Delete tasks.

   - Users can add new tasks, mark tasks as complete, edit existing tasks, or remove tasks they no longer need.

   - This functionality ensures users can maintain a clear and up to date task list, addressing forgetfulness and organizational challenges.

4. AI Prompter / Help Feature
 In order to get guidance without leaving the app, I need an AI assistant that can answer questions and provide suggestions.

  - The AI can suggest tools, offer workflow tips, or help users optimize their time.

  - This feature reduces frustration and helps users maximize productivity without needing to search externally for guidance.


## Integrations 

PlanBuddy will integrate the OpenAI API to provide AI powered functionality, including task suggestions, prioritization, and the AI Prompter feature. This integration allows the app to analyze user tasks, offer actionable advice, and generate personalized recommendations, transforming the user’s experience from a standard task manager to a smart, AI assisted productivity tool.
